
# Project 1: Rule-Based AI Chatbot 🤖

## Project Overview
This project involves developing a simple rule-based chatbot using Python. The chatbot interacts with users by responding to predefined inputs using conditional statements and a continuous conversation loop.

## Objectives
- Develop a basic conversational chatbot.
- Implement if-else decision-making logic.
- Handle greetings and exit commands.
- Maintain continuous conversations with users.

## Features
- Responds to different greetings.
- Answers predefined questions.
- Provides basic information about Artificial Intelligence and Python.
- Responds to expressions of gratitude.
- Recognises exit commands such as bye, exit, and quit.
- Handles unknown inputs with a default response.

## Technologies Used
- Python 3
- Google Colab

## Python Concepts Applied
- Variables
- User input and output
- While loops
- If-elif-else statements
- String methods
- Break statements

## How to Run
1. Open the notebook using Google Colab.
2. Run the code cell.
3. Enter a message when prompted.
4. Interact with the chatbot.
5. Type bye, exit, or quit to end the conversation.

## Project Learning Outcomes
This project improved my understanding of Python control flow, conditional logic, loops, and the basic principles behind rule-based conversational systems.
